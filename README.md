# Git & GitLab workshop

This workshop aims at learning basics of the version control with the well-known and widely used Git manager.
GitLab is used here as a remote code manager but GitHub can also be used ; only vocabulary may change a bit
between those two.

## How to use it ?
- Follow practicals in the order from 1 to 4
- The slides are available on [Zenodo](https://zenodo.org/records/18662531).

## Data
- `Edu-_RFP-_(5)` : downloaded from this [zenodo repo](https://zenodo.org/records/4248921)
- `blobs.tif` : contrast-reverted `blobs.gif` got from the standard distribution of Fiji `File -> Open Sample -> blobs`
